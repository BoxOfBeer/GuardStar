## Принцип: сначала «как снабжать», затем «что снабжать»

### Как (логистическая линия)

- Снабжение клетки (`_is_cell_supplied`, `GET /api/supply/state`) теперь требует:
  1. **Радиус** от своей планеты-хаба (как в фазе A: `5 + 3 × supplier_count`);
  2. **Непрерывный L-маршрут** от хаба до клетки (сначала шаги по X, затем по Y);
  3. На всех клетках пути **нет чужого флота** (`qty > 0`, другой `owner_player_id`) — иначе линия считается **оборванной**.
- В ответе `supply/state`: `route_clear`, `route_blocked_at` (координаты первой блокирующей клетки при необходимости), `supply_path: "manhattan_L"`.
- **Расход еды/воды по длине линии / конвой** — намеренно не внедрялись в этот шаг (следующий этап после стабилизации «как»).

### Что (еда / вода на планете)

- Таблица **`resources`**: колонки **`food`**, **`water`** (миграция `20260530_000012_resources_food_water.py`).
- **`economy.json`**: базовая выработка планеты **+1 еда**, **+1 вода** за сол (вместе с металлом/кристаллом/энергией/топливом).
- **Здания** (только клетка `planet`): `hydro_farm_t1` (+3 еды/сол), `atmospheric_reclaim_t1` (+3 воды/сол); требуют исследований `tech_hydroponics_1` / `tech_atmospheric_water_1`.
- **Технологии** (после `tech_logistics_1`): гидропоника и атмосферная вода с небольшим **`production_multiplier`** для еды и воды.
- Производство: общий расчёт в **`_planet_production_deltas`** (база + постройки с учётом снабжения клетки постройки + раса + **завершённые техи** + множитель влияния); используется в тике планеты и в превью сектора / `economy` в `world/state`.
- UI: верхняя панель и модалка планеты показывают еду/воду и их производство; подсказка по линиям снабжения в модалке.

## Население и «Сол»

- **`population_maintenance`** в `economy.json`: еда/вода за сол пропорционально населению (`per_1000_pop`).
- После выработки на планете списывается содержание; при **полном** запасе еды и воды — рост как раньше; при **недостатке** роста нет; при **остром дефиците** — медленное снижение численности.
- В API к `current_tick` добавлено **`current_sol`** (то же число) для смысла «игровой год».
- В интерфейсе (RU) **тик** заменён на **сол** / **сола** / **солов** где речь о игровом времени; кнопка ручного шага — **«Сол»**, автотик — **«Автосол»**.

## Логистика линий (еда/вода с хаба)

- В **`economy.json`**: **`supply_route_upkeep`** — базовый расход еды/воды за активный форпост **вне клетки планеты** в снабжении; опционально добавка за **манхэттен от хаба** (`*_per_manhattan_from_hub`).
- После производства на всех планетах за сол вызывается **`_apply_supply_route_logistics_tick`**: списание с **ресурсов планеты-хаба** (той же, что даёт L-маршрут); при нехватке — форпост **`offline`**, событие `outpost_offline` с **`reason: supply_logistics_unpaid`**.
- В **`_outpost_stats`** в **`supply_line`** для UI: хаб, стоимость за сол.

## Имперские расходы флотов

- В **`economy.json`**: **`fleet_empire_upkeep`** — списание **металла/кристалла** за сол с **капитальной (самой ранней)** планеты игрока за каждый флот (и опционально за корабли).
- В тике (`process_next_tick`) после производства/логистики вызывается **`_apply_fleet_empire_upkeep_tick`**; при нехватке — событие `fleet_maintenance_failed` и штраф по **локальной энергии** флота (`energy_penalty_on_unpaid`).

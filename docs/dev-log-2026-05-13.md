## События: `events.message` длиннее 255 → падение тика (PostgreSQL)

- **Причина:** `StringDataRightTruncation` при автотике — в **`events.message`** писалась строка **> 255** символов (колонка была `VARCHAR(255)`).
- **Исправление:** миграция [`20260527_000035_events_message_text.py`](server/app/db/migrations/versions/20260527_000035_events_message_text.py) — **`message` → `TEXT`**; модель [`event.py`](server/app/db/models/event.py); в **`_emit_event`** ([`_mixin_02.py`](server/app/services/world_service/_mixin_02.py)) — обрезка сверх разумного предела (**8192**), полный контекст остаётся в **`payload_json`**; safety-net: новая таблица `events` с **`TEXT`**, для существующего Postgres при длине ≤255 — **`ALTER … TYPE TEXT`** ([`dev_schema_safety_net.py`](server/app/db/dev_schema_safety_net.py)).
- **Действие на стенде:** `alembic upgrade head` (или перезапуск с safety-net на dev).
- **Версия:** `docs/GAME_VERSION` → **01.186**.

# 2026-05-12 — UI: фон страницы, прозрачные клетки, бордеры (фикс)
# Dev-log 2026-05-12

- **Карта / гекс:** починена визуальная «ломаная» сетка и рваные зелёные контуры зон — для `topology === "hex"` размер `.map-layer` и `viewBox` SVG больше не считаются как `max(span)×клетка` (это занижало ширину/высоту относительно реального bbox со сдвигом рядов). Используется `Math.max(offset*, scroll*)` по `#map-grid` (`mapLayerPixelRect`), плюс `syncMapLayerElBoxFromGrid()` **до** `renderFlightOverlay` в конце `renderMap`, чтобы SVG с `inset:0` не сжимались узким слоем до `renderZoneOverlay`.
- **Оверлей зон на гексе:** `segmentsToLoops` / `smoothClosedPathD` рассчитаны на ось-ориентированный периметр квадрата; для гекс-рёбер это давало ложные петли или сотни отдельных линий («лес» из `/`). Для гекса контур рисуется только дедуплицированными `<line>` (`dedupeHexBorderSegments`). Центры клеток для оверлея — через `getBoundingClientRect` относительно `.map-layer`, без цепочки `offsetParent`. В `renderZoneOverlay` сначала `syncMapLayerElBoxFromGrid`, затем размер `viewBox`.
- **Центрирование гекса:** `.map-grid.map-hex` — `align-items: flex-start` и `width: max-content`, чтобы ряды не растягивались на всю ширину слоя (иначе кластер «вжат» влево). Сегменты границы зоны: полудлина по ребру `hexS/2` вместо коротких «черточек».
- **Геометрия pointy-top axial:** горизонтальный отступ ряда был `(r−rMin)·hexS·√3/2` — это **не** совпадает с экранной формулой `x ∝ (q + r/2)`; клетки «плыли», границы и стрелки ломались. Теперь `paddingLeft = hexS·√3·(q_min(ряд) + r/2) − min_{окно}(hexS·√3·(q+r/2))`. Стрелки панорамы на краю: шаг из 6 осевых соседей центра с **минимальным** `jsHexDistance` до клетки (не евклидов скаляр в (q,r)).
- **Масштаб и стрелки:** гекс после базового `computeMapLayoutCellsPx` **дотягивается** под `.map-wrap` (bbox + cap `maxCellPx`). Стрелки: сдвиг `--pan-tx/ty` по радиусу в координатах раскладки.
- **Мигание карты:** `applyMapCellSizeFromContainer` (ResizeObserver + первый rAF после загрузки) подставлял квадратную сетку в `--map-layout-cell-*`, перетирая гекс → краткий кадр «полоски». Для `topology === "hex"` теперь вызывается **`renderMap()`**, без подмены размеров из `computeMapLayoutCellsPx`.
- **Границы зон на гексе (усиление):** после сборки контура — **2 итерации Chaikin** по полигону (`chaikinClosedLoop`), затем `smoothClosedPathD` с `joinR ≈ min(cell)×0.58` и `edgeCapMul=0.78`. Одних квадратичных скруглений на сырой «пиле» мало. Версия `docs/GAME_VERSION` → `01.142`.
- **Карточки строительства (модал планеты):** «−», **поле ввода числа** (1–100), «+» и «Построить» в **одну строку** (`flex-wrap: nowrap`), `<input type="number" class="build-qty-val">`, кламп на blur/change/Enter; при недоступности типа поле и ± отключаются. Версия `docs/GAME_VERSION` → `01.143`.
